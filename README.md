# Spana Website

A modern, responsive website for Spana - a revolutionary service provider platform that connects users with trusted service professionals across multiple industries.

## About Spana

Spana is a service provider platform similar to Uber, but for multiple service categories. Our platform makes it easy to discover, book, and manage quality services from verified professionals.

## Features

- **Service Discovery**: Find trusted service providers across multiple categories
- **Easy Booking**: Simple and intuitive booking process
- **Verified Professionals**: All service providers are vetted and verified
- **Real-time Updates**: Track your service requests in real-time
- **Secure Payments**: Safe and secure payment processing

## Technology Stack

- React 19
- Vite
- Modern CSS with CSS Variables
- Responsive Design

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
